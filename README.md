# Генератор номеров

Статический сайт для генерации уникальных номеров по шаблону `SNNNSS`.

- `S` — одна из букв: `P`, `E`, `C`, `O`;
- `N` — цифра от `0` до `9`.

Например: `P123EO`.

## Использование

1. Откройте файл `index.html` в браузере.
2. Укажите нужное количество номеров. По умолчанию — `20`.
3. Нажмите **«Генерация»**.
4. Нажмите на нужный номер, чтобы скопировать его в буфер обмена.

Всего доступно 64 000 уникальных комбинаций.

## Публикация на GitHub Pages

1. Загрузите в корень репозитория файлы `index.html`, `styles.css` и `script.js`.
2. В настройках репозитория откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/(root)`, затем сохраните настройки.

Через несколько минут сайт будет доступен по адресу:

```text
https://<ваш-логин>.github.io/<имя-репозитория>/
```
